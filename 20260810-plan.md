# Plan — giuli-wishes (Lista regali compleanno Giulia)

Data: 2026-08-10
Stato: proposta (in attesa di conferma stile + dati reali)

## Cosa costruiamo

Sito **statico** (GitHub Pages), mobile-first, per la festa di compleanno di Giulia.
Gli invitati vedono la lista regali, dichiarano "l'ho preso" oppure "contribuisco".
Niente backend: dati letti da **Google Sheet pubblici**, azioni raccolte con **Google Form** precompilati, stato aggiornato con polling (default 30 s).

Tema grafico: **sole / fiori / foglie**, palette giallo · bianco · verde salvia. Semplice e minimale.

---

## Architettura

| Livello | Scelta |
|---|---|
| Hosting | GitHub Pages |
| Frontend | HTML + CSS + Vanilla JS (nessuna libreria) |
| Dati regali | Google Sheet pubblico "Regali" (CSV via `gviz/tq` o export `csv`) |
| Dati stato | Google Sheet pubblico "Risposte" (dal Form) |
| Azioni | Google Form precompilato (`entry.xxx` via query string) |

### Sheet Regali — colonne REALI (da "Regali" di Valentina)
| Colonne attuali | Uso nel sito |
|---|---|
| `Titolo` | nome regalo |
| `Descrizione` | descrizione |
| `Links` | 1+ URL separati da `-` o spazi (pulsante "Vedi prodotto") |
| `Immagine` | URL foto |
| `Nascosto` (`Sì`) | esclude il regalo dalla lista (già preso / non disponibile) |

**Gap rilevati sullo Sheet reale** (da aggiungere quando crei anche il Form, servono per il matching con le risposte):
- `id` — necessario per collegare regalo ↔ risposte "acquisto/contributo" del Form. Fallback ora: derivato dallo slug di `Titolo`.
- `prezzo` — facoltativo, al momento assente (si mostra solo se presente).
- `ordine` — assente: uso l'ordine delle righe nel CSV (stabile finché non riordini lo sheet).
- Una riga vuota in fondo (da rimuovere) e `Nascosto` oggi usato come "escluso dalla lista" (≠ display disabilitato in fondo richiesto dallo spec).

### Sheet Risposte — colonne
`Timestamp` · `ID regalo` · `Tipo` (acquisto|contributo) · `Nome` · `Messaggio`

### Logica di stato (unione frontend)
- **Acquistato** = `acquistato==TRUE` **oppure** esiste una risposta `Tipo==acquisto` per quell'id.
- **Contributori** = conteggio risposte `Tipo==contributo` per quell'id.

## Flusso frontend

1. Legge Sheet Regali + Sheet Risposte (fetch `csv`).
2. Costruisce vista unificata (stato + contributori per id).
3. Ordina: disponibili per `ordine`, poi acquistati per `ordine`.
4. Render delle card con skeleton loader al primo caricamento.
5. Polling ogni **30 s** (configurabile in `config.js`) in background.
6. Aggiornamento **differenziale**: ricalcola solo le card cambiate; stabilizza card già prese con transizione CSS morbida; badge contributori con conteggio animato.
7. Rispetto di `prefers-reduced-motion`.

### Card regalo
- Immagine (lazy loading) · Nome · Descrizione · Prezzo (opzionale) · Link "Vedi prodotto"
- Se disponibile: pulsanti **"I l'ho preso"** e **"Voglio contribuire"** (+ badge "👥 N contributori" se >0)
- Se acquistato: card desaturata, badge "✅ Già preso", pulsanti disabilitati, "Questo regalo è già stato preso ❤️"

### Pulsanti → Google Form
Apri Google Form precompilato con query string:
`?entry.<campo_id>=<id>&entry.<campo_tipo>=acquisto|contributo`

## Design — 3 proposte di stile (da scegliere)

Palette di base condivisa (giallo / bianco / verde salvia):

```
--cream:    #FFFBF1   (sfondo caldo)
--sage:     #9CAF88   (verde salvia)
--sage-soft:#D9E3CE
--sun:      #F6C453   (giallo sole)
--sun-soft: #FCE8B3
--ink:      #33402F   (testo)
--white:    #FFFFFF
```

Font (evito Inter/Roboto): **titoli script "Caveat"/"Kalam"**, **corpo arrotondato "Quicksand"/"Nunito"** — tono amichevole da festa bambini.

### A — "Sunshine & Petals" (ispirata agli Etsy sunshine pack)
- Sfondo cream con raggi di sole soffusi + petali/floretti sparsi ai bordi.
- Titolo in script (Caveat) grande, colore sole.
- Card bianche con angoli molto arrotondati, ombra leggera, badge sole.
- CTA giallo pieno con testo scuro; secondario sage outline.
- → calda, giocosa, "festa".

### B — "Garden Meadow"
- Background gradiente cream→sage-soft con foglie disegnate a mano come watermark (semi-trasparenti in basso/ai lati).
- Palette meno contrastata, accenti verdi dominanti; il giallo solo su CTA e badge.
- Card con bordo sage, stile "plant journal", font Quicksand.
- → organica, morbida, botanica.

### C — "Minimal Bouquet" (editoriale pulita)
- Molto bianco, bande sage orizzontali per separare le sezioni (header/hero/lista).
- Piccoli mazzetti/floretti minimali come decorazione, uso sobrio del giallo (solo pulsanti "L'ho preso").
- Tipografia più ordinata (Nunito), più spazio bianco.
- → pulita, elegante, la più "app".

## Proposta consigliata
**A — "Sunshine & Petals"**: sposa meglio i riferimenti Etsy sunshine, il tema sole/fiori e i colori richiesti, mantenendosi semplice e perfetta per l'uso con card piene di immagini.
